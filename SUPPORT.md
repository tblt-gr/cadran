# Support

Cadran Budget is in early development and does not yet provide guaranteed user support.

- Use the **Bug report** form for reproducible problems.
- Use **Feature or task** for proposals aligned with the documented product scope.
- Use GitHub Discussions for general questions.
- Never report a vulnerability publicly; follow [`SECURITY.md`](./SECURITY.md).

Always remove secrets, exports, statements, transaction labels, balances, and other financial data
before sharing logs or screenshots.
